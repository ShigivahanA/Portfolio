## Short Description

This repository contains a **production-ready personal portfolio website** that highlights projects, certifications, skills, and a contact form.  
It uses a **restrained 5-color palette** for a professional feel:

- **Black** `#000000`  
- **Deep Navy** `#14213d`  
- **Accent Gold** `#fca311`  
- **Light Gray** `#e5e5e5`  
- **White** `#ffffff`

Animations are implemented with **Framer Motion**, and all imagery & assets are stored in `src/assets`.

---

## Features

- **Modern, responsive layout** (mobile → desktop)  
- **Hero section** with animated heading and heartbeat-shaped section dividers  
- **Projects grid** + detailed project pages with image gallery & zoom modal  
- **Certificates gallery** + detail pages (with optional verification links)  
- **Contact form** integrated with **Web3Forms** (no backend required)  
- **Smooth scroll + accessible navigation**  
- **Framer Motion animations** (staggered entrance, hover states, smooth transitions)  
- **Tailwind CSS** for utility-first styling  
- Easy to extend and customize  

---

## Tech Stack

- **React (Vite)**  
- **Tailwind CSS**  
- **Framer Motion (motion/react)**  
- **React Router**  
- **Lucide Icons**  
- **Web3Forms** for contact submissions  
- Deployed to **Vercel** (recommended)
